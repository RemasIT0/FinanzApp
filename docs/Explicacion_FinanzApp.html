◈ FinanzApp — explicación del código

Python + MySQL. App de escritorio y versión web para el celular.

Cómo usarla

Abrir en la computadora

1. Enciende MySQL (servicio de MySQL o XAMPP/Workbench).
2. Abre una terminal en la carpeta finanzapp.
3. Escribe: python src/main.py

La primera vez: pip install -r requirements.txt. Si MySQL no conecta, la app te pide servidor, puerto, usuario y contraseña.

Celular

python src/main_web.py → abre en el celular la dirección que aparece (mismo WiFi).

Recuperar contraseña

Una sola vez: entra a la app → Configuración → Datos → Configurar correo de envío → pon un Gmail y su contraseña de aplicación.
Cuando la olvides: en el login toca ¿Olvidaste tu contraseña? → tu correo → Enviar código → escribe el código de 6 dígitos y la contraseña nueva.

Si nadie puede entrar y el Gmail no está configurado, la misma ventana de recuperación tiene el botón para configurarlo.

Conectar el correo (avisos del banco)

1. En tu Gmail activa la verificación en dos pasos.
2. Ve a myaccount.google.com/apppasswords y crea una contraseña de aplicación (16 letras).
3. En la app: Correo → Conectar correo → Gmail, tu correo y esas 16 letras → Guardar.
4. Enciende tu banco en «Bancos que se leen» → Sincronizar ahora → revisa y Guardar.

Explicación general

La app está dividida en 3 capas. Cada una solo habla con la de abajo:

Pantallas
ui/ y web/→Lógica
utils/, email_parser/→Datos
database/*_dao.py→MySQL
  • Pantallas: lo que ves. Nunca escriben SQL.
  • Lógica: leer CSV, leer correos, cálculos, validaciones.
  • Datos (DAO): un archivo por tabla con todo su SQL.

Qué pasa al abrirla

main.py→inicializar_bd()→Login→VentanaPrincipal→Secciones

Cada sección (Inicio, Historial, Reportes, Importar, Correo, Configuración) es un panel que se crea una vez y se actualiza con refrescar() cada vez que lo abres.

Reglas importantes

  • El monto siempre es positivo; el campo tipo dice si es gasto o ingreso.
  • El saldo no se guarda: se calcula (saldo inicial + ingresos − gastos).
  • Las contraseñas de correo van en el llavero de Windows, nunca en la base de datos.
  • Las contraseñas de usuario se guardan cifradas con bcrypt.

Casi 6 de cada 10 líneas están en ui/, las pantallas de escritorio. Es lo más grande porque en CustomTkinter todo se dibuja con código: cada botón, etiqueta, color y posición es una línea de Python (no hay un diseñador visual). Lo más pesado son ventana_config.py (~480), ventana_correo.py (~400) y ventana_principal.py (~380).

La lógica “inteligente” (importar, calcular, leer correos) es más chica y está en utils/ y email_parser/.

Cómo se conectó la base de datos

  1. Datos de conexión en data/config.json: host localhost, puerto, usuario root y contraseña.
  2. conexion.py usa la librería mysql-connector-python. obtener_conexion() lee config.json y llama a mysql.connector.connect(...).
  3. Al abrir la app, inicializar_bd() ejecuta database_schema.sql: crea la base finanzapp y las tablas si no existen. Por eso no tienes que crearlas a mano.
  4. Cada consulta abre una conexión, ejecuta y la cierra (try/finally). Simple y sin conexiones colgadas.
  5. Los DAO solo llaman 4 funciones: consultar, consultar_uno, ejecutar, ejecutar_varios.
# Ejemplo real (transacciones_dao.py)
ejecutar("INSERT INTO transacciones (...) VALUES (%s, %s, ...)", (cuenta_id, categoria_id, ...))

Los %s son parámetros: MySQL los rellena de forma segura, así nadie puede “inyectar” SQL escribiendo cosas raras.

Tablas

  • usuarios → cuentas → transacciones ← categorias
  • presupuestos (uno por categoría y mes)
  • cuentas_email, plantillas_email, emails_procesados (correo bancario)
  • recuperaciones (códigos para cambiar contraseña)

Cómo funciona el correo

Hay dos conexiones distintas:

1. Leer avisos del banco (IMAP) — email_parser/lector_email.py

Tu Gmail/Yahoo→ IMAP 993 →Buscar por remitente (bbva…)→Bajar cabeceras→Bajar cuerpo→Regex: monto, fecha, comercio→Vista previa
  • Entra con una contraseña de aplicación (no tu contraseña normal), guardada en el llavero de Windows.
  • Abre la bandeja en solo lectura: no marca nada como leído.
  • Cada banco tiene una plantilla con expresiones regulares. Ej. monto: \$\s?([\d,]+\.\d{2}) encuentra “$1,250.50”.
  • Corre en un hilo aparte (threading) para que la ventana no se congele.
  • Los correos ya guardados/descartados se anotan en emails_procesados y no vuelven a salir.

2. Enviar códigos (SMTP) — utils/enviar_correo.py

Pides código→Se crea y guarda cifrado en BD→ SMTP 465 →Gmail de la app lo envía→Llega a tu correo
  • Sale desde el Gmail de la app (configurado una vez), con su contraseña en el llavero.
  • El código vence en 15 min, permite 5 intentos y solo se puede pedir uno por minuto.

Qué hace cada archivo y sus funciones

Arranque

main.py: Abre la app de escritorio.

  • App.__init__ — Crea la ventana, la centra y llama a iniciar().
  • _aparecer — Fundido de entrada de la ventana.
  • _cambiar_pantalla — Destruye la pantalla actual y muestra otra.
  • iniciar — Conecta a MySQL; si falla, pide los datos de conexión.
  • mostrar_login / entrar — Cambian entre login y ventana principal.

main_web.py: Arranca la versión web para el celular.

  • ip_local — Averigua la IP de la PC en el WiFi.
  • (bloque principal) — Crea la clave de sesiones, la BD y arranca el servidor en el puerto 8000.

database/ — habla con MySQL

conexion.py: La ÚNICA puerta a MySQL.

  • obtener_conexion — Abre una conexión con los datos de config.json.
  • inicializar_bd — Ejecuta database_schema.sql (crea BD y tablas).
  • consultar / consultar_uno — SELECT → lista de diccionarios / una fila.
  • ejecutar — INSERT/UPDATE/DELETE → id insertado.
  • ejecutar_varios — Inserta muchas filas de golpe.

usuarios_dao.py: Usuarios y contraseñas.

  • registrar — Crea usuario (contraseña con bcrypt), categorías y cuenta Efectivo.
  • iniciar_sesion — Compara la contraseña con el hash guardado.
  • existe_email / obtener — Buscar usuario.
  • crear_codigo_recuperacion — Genera código de 6 dígitos, lo guarda cifrado, vence en 15 min.
  • cambiar_password_con_codigo — Valida código (5 intentos) y cambia la contraseña.
  • borrar_codigo — Borra el código si el envío falló.

cuentas_dao.py: Bancos, tarjetas, efectivo.

  • listar — Cuentas con su saldo calculado (inicial + ingresos − gastos).
  • crear / actualizar / eliminar — Altas, cambios y bajas (borrar cuenta borra sus movimientos).

categorias_dao.py: Categorías del usuario.

  • listar / mas_usadas — Todas, o las 4 más usadas (gasto rápido).
  • crear / actualizar / eliminar — Altas, cambios y bajas.
  • crear_por_defecto — Las 13 categorías iniciales.

transacciones_dao.py: Movimientos y totales para gráficas.

  • crear / crear_varias / actualizar / eliminar — Guardar y modificar movimientos.
  • obtener — Un movimiento solo si es del usuario.
  • buscar / ultimas — Búsqueda con filtros; últimos 5.
  • firmas_existentes — Para detectar duplicados al importar.
  • totales / gastos_por_categoria / totales_por_mes — Datos de tarjetas y gráficas.

presupuestos_dao.py: Límites mensuales.

  • listar / alertas — Presupuestos con lo gastado; los que pasan del 80%.
  • guardar / eliminar / copiar_de_mes — Crear, borrar, copiar de otro mes.

correo_dao.py: Correo conectado y correos ya leídos.

  • obtener / guardar / eliminar — La cuenta de correo del usuario.
  • marcar_sincronizado — Guarda la hora de la última revisión.
  • ids_procesados / marcar_procesados — Para no mostrar dos veces el mismo aviso.

plantillas_dao.py: Patrones (regex) para leer avisos de cada banco.

  • crear_por_defecto — BBVA, Santander, Banorte, Nu, Mercado Pago.
  • listar / crear / actualizar / cambiar_activo / eliminar — Administrar bancos.

email_parser/ — leer avisos del banco

lector_email.py: Lee tu buzón por IMAP y saca monto, fecha y comercio.

  • guardar/leer/borrar_password — Contraseña de aplicación en el llavero de Windows.
  • conectar / probar_conexion — Entrar al buzón.
  • sincronizar — Función principal: busca avisos nuevos.
  • _leer_avisos / _descargar — Busca por remitente, baja cabeceras y luego cuerpos.
  • plantilla_para / extraer / _grupo — Identifica el banco y aplica las regex.
  • texto_del_correo / _fecha_del_correo — Quita HTML y lee la fecha.

utils/ — lógica sin pantallas

config.py: Lee y guarda data/config.json.

  • cargar_config / guardar_config / actualizar_config — Leer, guardar y cambiar valores.

procesador_csv.py: Importar estados de cuenta.

  • leer_archivo — Lee CSV/Excel y salta el encabezado del banco.
  • detectar_columnas / detectar_signo — Adivina columnas y si el gasto viene negativo.
  • convertir_monto / convertir_fecha — Entiende $1,234.56, 1.234,56, (500), fechas.
  • procesar — Filas → movimientos.
  • sugerir_categoria — Por palabras clave (oxxo → Supermercado).

calculos.py: Fechas y dinero.

  • formato_moneda — 1234.5 → $1,234.50.
  • rango_mes / mover_mes / ultimos_meses — Manejo de meses.
  • tasa_ahorro / proyeccion_fin_mes — Porcentaje de ahorro y gasto proyectado.

validadores.py: Revisa lo que escribe el usuario.

  • email_valido / password_valida / convertir_monto / ultimos4_validos / texto_requerido — Validaciones de formularios.

temas.py: Colores y fuentes.

  • color / estilo_tablas / opciones_calendario — Tema claro u oscuro.

exportar.py: Sacar datos.

  • a_csv / a_pdf — Exportar historial.
  • exportar_respaldo / importar_respaldo — Respaldo JSON completo.

enviar_correo.py: Envía correos desde el Gmail de la app (SMTP).

  • remitente / configurar_remitente — Ver y guardar el Gmail de envío.
  • enviar / enviar_codigo — Mandar el correo con el código.
  • mensaje_error / _entrar — Errores entendibles; login a Gmail.

recuperacion.py: Pedir código (lo usan escritorio y web).

  • disponible / solicitar — ¿Hay Gmail? Crear y enviar código.

ui/ — pantallas de escritorio (la parte más grande)

  • PanelLogin — Iniciar sesión / crear cuenta, enlace «¿Olvidaste tu contraseña?».
  • DialogoRecuperar — Ventana de 2 pasos: correo → código + contraseña nueva.
  • PanelConexion — Pide datos de MySQL si no conecta.

  • VentanaPrincipal.mostrar — Cambia de sección (crea cada panel una vez).
  • programar_correo — Revisión automática del correo cada X horas.
  • cambiar_tema — Modo claro/oscuro.
  • PanelDashboard.refrescar — Tarjetas, alertas, gráficas y últimos movimientos.
  • _guardar_rapido — Gasto rápido.

ventana_registro.py: Formulario nuevo/editar movimiento.

  • _mostrar_categorias / _guardar — Botones de categoría y guardar en BD.

ventana_transacciones.py: Historial.

  • refrescar / _editar / _eliminar / _exportar — Filtrar, editar, borrar, exportar.

ventana_reportes.py: Gráficas del mes.

  • refrescar / _proyeccion — Dona, top 5, 12 meses, proyección.

ventana_importar.py: Importar CSV/Excel.

  • _elegir_archivo / _previsualizar / _importar — Leer, vista previa, guardar.

ventana_correo.py: Conectar correo y revisar avisos.

  • DialogoCorreo — Pide Gmail/Yahoo + contraseña de aplicación y la prueba.
  • sincronizar / _trabajo / _revisar_hilo — Lee el correo en un hilo aparte sin congelar la ventana.
  • _guardar / _descartar — Guarda o descarta los movimientos detectados.

  • PanelConfig — Pestañas: Cuentas, Categorías, Presupuestos, Datos.

componentes/: Piezas reutilizables.

  • Boton, Tarjeta, Grafica, TablaTransacciones, mostrar_aviso, animaciones — Botones, tarjetas, gráficas matplotlib, tabla, avisos y animaciones.

web/ — versión para celular

  • inicio / gasto_rapido — Pantalla principal.

  • movimiento_nuevo / editar / guardar / eliminar — Formulario (revisa que la cuenta sea del usuario).
  • reportes — Gráficas hechas con CSS/SVG.

templates/*.html: El HTML de cada pantalla (Jinja2).

static/estilo.css: Diseño para celular, claro/oscuro automático.
